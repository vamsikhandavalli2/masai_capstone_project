# Data Pipeline

## Overview

This module implements a web-scraping and data-processing pipeline for book information.

The implementation uses the **Books to Scrape** website as the data source.

The overall workflow is:

```text
Web Scraping
     ↓
Data Cleaning
     ↓
Currency Conversion
     ↓
SQLite Database
     ↓
SQL Queries
     ↓
pandas Analysis
```

---

## Technologies

The implementation uses:

* Python
* Requests
* BeautifulSoup
* pandas
* SQLite
* NumPy

---

# Web Scraping

The scraper retrieves book information from multiple book categories.

The implementation extracts the following information:

* Title
* Price
* Star rating
* Availability
* Category

The scraper navigates through the category pages and collects the available book information.

---

# Data Cleaning

The scraped information is converted into structured values before being stored.

### Price

The GBP currency symbol is removed and the price is converted to a numeric value.

### Rating

Star-rating text is converted to a numerical representation:

```text
One   → 1
Two   → 2
Three → 3
Four  → 4
Five  → 5
```

### Availability

The availability information is converted into a boolean-style value indicating whether the book is in stock.

---

# Currency Conversion

The implementation uses the fixed exchange rate:

```text
1 GBP = 105.50 INR
```

The INR price is calculated from the GBP price.

```text
price_inr = price_gbp × 105.50
```

No live exchange-rate API is used.

---

# SQLite Database

The implementation creates a SQLite database named:

```text
books.db
```

The database design separates book and category information.

The main tables are:

```text
categories
books
```

The `books` table contains the book-level information and a category reference.

The `categories` table contains the category information.
